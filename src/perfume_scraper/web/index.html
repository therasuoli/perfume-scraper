04 / DATA BANK

① ادغام فایل‌های خروجی

حداکثر ۱۰ فایل JSON یا XLSX را انتخاب کنید. فایل‌ها خوانده، فیلدها یکپارچه و محصولات تکراری با حفظ اطلاعات کامل‌تر ادغام می‌شوند.

فایلی انتخاب نشده

② استخراج لینک‌های دستی

آدرس صفحات فروشگاه یا محصولات را وارد کنید؛ نتایج در بانک اطلاعات ذخیره می‌شوند.

③ استخراج از Scento API

جستجوی API عمومی سنتو، دریافت پروفایل عطر، برند، نت‌ها، خانواده بویایی و توضیحات؛ دسته‌بندی و ذخیره مستقیم در بانک و Supabase (در صورت تنظیم کلیدها).

API جستجو-محور است؛ عبارت‌های متعدد را هرکدام در یک خط وارد کنید. درخواست‌ها با فاصله اجرا می‌شوند.
